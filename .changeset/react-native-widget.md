New `@fishaudio/agent-widget-react-native`: the drop-in voice widget for React Native apps. A floating button opens a call panel with live transcript, text input, mute, consent and tool chips, the counterpart of the web `<fish-agent>` element, built on `@fishaudio/agent-react-native`'s `useConversation`. The web widget now shares its settings, transcript store and helpers with it through an internal package; its behavior and exports are unchanged.
