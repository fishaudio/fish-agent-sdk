New: a native iOS SDK, the Swift package `FishAgent`. It is headless and follows the Web and React Native SDKs: the same session options, events, error codes, end reasons and client tool rules, behind one `Conversation` object with published properties. It adds what a phone needs: the microphone permission and audio routing (`auto`, `speaker`, `earpiece`). Checked on an iPhone 12; the docs list what was checked and what is still open.
